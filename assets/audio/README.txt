AUDIO DE PERSONAJES

Para que suene la frase de Moncayo, copia el archivo MP3 real llamado exactamente Moncayo.mp3 dentro de esta carpeta:
assets/audio/Moncayo.mp3

El archivo debe contener una grabación válida y no estar vacío. La ruta ya está configurada en assets/js/app.js. Si el reproductor muestra 0:00 / 0:00, comprueba que el MP3 exista y se pueda reproducir en el computador.
